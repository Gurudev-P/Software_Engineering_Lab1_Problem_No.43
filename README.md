# Lab 1 — Requirements Engineering and UML Use-Case Modelling

**Problem Statement #43:** Feature Flag & Dynamic Config Manager

This repository contains the Lab 1 deliverables for the Feature Flag & Dynamic Config Manager.

## Submission files

| File | Purpose |
|---|---|
| `Requirements_Table_Problem43_Updated.xlsx` | Portable requirements table for the five functional and two non-functional requirements |
| `Requirements_Table_Problem43_Updated.pages` | Editable Apple Pages source of the requirements table |
| `02_Use_Case_Flow_Problem43.pdf` | One-page use-case flow with preconditions, postconditions, main success scenario, and alternate flow |
| `03_UML_Use_Case_Diagram_Problem43.pdf` | UML use-case diagram showing the actors, use cases, and `«include»` / `«extend»` relationships |

## Requirements table contents

The requirements spreadsheet includes exactly:
- Five functional requirements: FR-001 through FR-005.
- Two non-functional requirements: NFR-001 and NFR-002.

Each requirement includes its ID, type, description, priority, acceptance criteria, and rationale.

## Use-case model

The UML diagram models the Software Engineer, Release Manager, and Client Application / SDK actors. The accompanying use-case flow documents **UC-01 — Evaluate Feature Flag**, including its alternate flow for an environment override.

## Viewing the files

Use the Excel file for a platform-independent copy of the requirements table. The `.pages` file is the editable Apple Pages source and requires Apple Pages to open.

The two PDF files can be viewed directly in a browser or PDF reader.
